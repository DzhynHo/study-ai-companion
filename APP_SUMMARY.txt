🚀 QUICK START:

1. ZAINSTALUJ ZALEŻNOŚCI:
   $ flutter pub get

2. USTAW API KEY:
   Otwórz: lib/core/config.dart
   Zastąp: 'sk-ant-v7-YOUR_KEY_HERE'
   Uzyskaj klucz: https://console.anthropic.com/

3. URUCHOM:
   $ flutter run

4. TESTUJ:
   - Utwórz przedmiot
   - Wgraj PDF lub zdjęcie
   - Wybierz tryb nauki
   - Gotowe! 🎉

🆘 TROUBLESHOOTING:

❌ "API key invalid"
   → Sprawdź format klucza
   → Zregeneruj w consoli

❌ "Hive failed to open"
   → flutter clean && flutter pub get

❌ "PDF nie ekstraktuje"
   → Użyj PDF z tekstem (nie skan)
   → Max rozmiar: 50MB

❌ "Aplikacja się nie buduje"
   → flutter clean
   → flutter pub get
   → flutter run -v
